# 更新日志

> 版本号规则：除非明确要求改动主/次版本号，每次更新只递增最后一位（`1.0.0 → 1.0.1 → 1.0.2 …`）。

## 1.0.1

**界面**

- 偏好设置入口图标改为齿轮，线宽与其它顶栏图标一致
- 设置页新增「默认画质」，可选 4K / 1080P60 / 1080P+ / 1080P / 720P / 480P / 360P / 自动

**播放**

- 播放时优先使用默认画质；**视频不支持该画质时，自动使用它能提供的最高画质**
- **音量跟软件走**：记住上次调节的音量，换视频、重开软件都沿用；播放器内（含全屏）调节也会写回设置
- 视频页控制条新增「弹幕设置」按钮：

| 分组 | 项目 |
| --- | --- |
| 按类型过滤 | 滚动 / 固定 / 彩色（可分别开关） |
| 显示行为 | 弹幕随屏幕缩放、防挡字幕、智能防挡弹幕 |
| 屏蔽 | 弹幕屏蔽词（支持逗号/顿号分隔）、同步屏蔽列表 |
| 外观 | 显示区域、不透明度、弹幕字号、弹幕速度——拖动即生效，无需重开播放器 |

**设置**

- 「更新地址」默认填为 `https://github.com/NstyZ/BiliFound`；填写仓库主页地址也能直接用（会自动换成 Releases API）
- 清空更新地址时会自动恢复默认仓库，不再直接停用检查

## 1.0.0

首个公开版本：Windows（x64）与 macOS（Apple Silicon）双平台，自绘界面、自建播放器、原生直播与弹幕。
