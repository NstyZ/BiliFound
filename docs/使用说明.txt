BiliFound 1.0.0 · Windows 版（64 位）
==================================================

【三种拿法，挑一种】

① 安装版  BiliFound-1.0.0-Setup-x64.exe
   双击 → 选择安装位置 → 自动创建桌面和开始菜单快捷方式；
   以后从「开始菜单 → BiliFound」启动，卸载走「设置 → 应用」或安装目录里的
   「Uninstall BiliFound.exe」。适合长期使用、也适合发给别人。

② 便携版  BiliFound-1.0.0-Portable-x64.exe
   单个 exe，双击即用，不写注册表、不留快捷方式（运行时会自解压到临时目录）。
   适合放 U 盘、或者只想先试试。

③ 绿色目录 BiliFound-1.0.0-win32-x64.zip
   解压后双击 BiliFound.exe。适合想直接看程序文件、或放在自己指定目录里。

   ⚠ 不管用哪种，都请放在普通位置（桌面、D:\Apps、U 盘等）。
     不要放在 E:\ai\杂\Za New\... 这类 DSH 工作区目录里直接运行：
     该目录的文件被系统标成「低完整性」，Chromium 沙箱起不来，
     程序会一闪就退出（退出码 0x80000003）。复制到桌面或 D:\ 下就正常。

【首次使用】

1. 启动后是未登录状态：点左下角「登录」，在弹出的窗口里扫码/账号登录。
   登录态保存在本机，下次打开自动恢复。
2. 数据与设置位置：
      %APPDATA%\BiliFound\settings.json     主题、背景、播放设置、窗口位置
      %APPDATA%\BiliFound\backgrounds\      自定义背景图
      下载目录：默认 %USERPROFILE%\Downloads\BiliFound
                （偏好设置 → 下载 → 更改目录… 可改）
   想彻底重来：关掉程序，删掉 %APPDATA%\BiliFound 文件夹即可。

【快捷键（Windows）】

  Ctrl+F / Ctrl+K     聚焦搜索 / 命令面板
  Ctrl+,              偏好设置
  Ctrl+Shift+D        深色 / 浅色切换
  Ctrl+Shift+I        沉浸模式（Esc 退出）
  Ctrl+\              收起 / 展开侧边栏
  Ctrl+[  Ctrl+]      后退 / 前进（也支持 Alt+← / Alt+→）
  F5 / Ctrl+R         刷新当前页面
  F11                 窗口全屏
  Alt+F4              退出
  空格 / J / K / L     播放暂停 / 后退 5 秒 / 播放暂停 / 前进 5 秒
  视频页「全屏」按钮   播放器全屏（Esc 或右上角 × 退出）
  双击播放器画面       播放器全屏切换

【功能范围】

  与 macOS 版一致：首页推荐 / 热门 / 排行榜 / 番剧影视 / 直播 / 动态 / 评论 /
  私信 / 专栏 / 搜索 / UP 主页 / 收藏 / 历史 / 稍后再看 / 关注粉丝 / 消息中心 /
  自建播放器（DASH 双流、弹幕、字幕、倍速、截图、画中画）/ 视频下载（MP4 合并流）/
  液态玻璃主题 / 自定义背景 / 命令面板。

  Windows 版这一路新增的：
    - 首页顶部「大轮播 + 侧卡」大小混排，下面是统一网格；列数随窗口宽度自动变
      （小窗 4 列、全屏 5 列），右上角「换一批」可以重新拉一批推荐
    - 搜索框：点开有「搜索历史 + bilibili 热搜」，输入时给联想词，命中的字标红，
      ↑↓ 选择、Enter 搜索、Esc 关闭
    - 直播页：左边播放器、右边单独一栏弹幕（带用户等级、粉丝牌、舰队徽章），
      右下角能点赞、发表情；「屏蔽」里可以按关键词、进场/礼物、最低等级过滤弹幕
    - 设置 → 设计风格：经典 / 杂志 / 极简 / 米纸 / 霓虹 五种预设，点一下立即换装

  已知限制：
    - 4K / 杜比需要大会员，取决于账号权益
    - DASH-only 片源无法下载，会给出明确提示
    - 私信不支持撤回与语音
    - 直播「点赞」是本地计数与动效，不会上报到 B 站
    - 程序未做代码签名，首次运行 Windows 可能提示
      「Windows 已保护你的电脑」→ 点「更多信息 → 仍要运行」即可

【出问题时】

  - 双击没反应 / 一闪就退出：
      先确认是否放在了上面说的 DSH 工作区目录里；
      再确认没被杀毒软件拦截（Electron 应用首次运行常被拦）。
  - 界面白屏：
      偏好设置 → 清除缓存；或删掉 %APPDATA%\BiliFound 重来。
  - 想看日志：在安装目录打开命令行执行
      BiliFound.exe --enable-logging=stderr
